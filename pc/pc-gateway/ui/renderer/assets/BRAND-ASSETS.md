# Product brand assets

These assets are used only to identify supported third-party integrations.

- `hermes-agent.png` — upstream `website/static/img/apple-touch-icon.png` from [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent).
- `openclaw.svg` — OpenClaw crab artwork from the user-specified [Homarr dashboard-icons asset](https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/openclaw.svg).
- `openai-light.svg` — OpenAI light mark from the user-specified [Homarr dashboard-icons asset](https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/openai-light.svg).
- `openai-readme.svg` — README presentation tile derived from `openai-light.svg`; the dark background keeps the original light mark visible in both GitHub themes.
- `elevenlabs.png` — ElevenLabs mark supplied by the upstream AgentCall project owner.
- `groq.svg` — Groq bolt mark drawn for Arynox AI Call Assistant branding; Groq's name and artwork identify interoperability only.
- `supertonic-symbol.svg` — Supertonic symbol from the user-specified [Supertonic interface asset](https://supertone-supertonic.static.hf.space/img/supertonic_symbol.svg).

The README displays the upstream or owner-supplied marks from
`docs/assets/brands`. `openai-readme.svg` changes only the presentation canvas:
its dark tile keeps the original light OpenAI mark visible in both GitHub
themes.

Downloaded from each project's default branch on 2026-07-23. Product names and
logos remain the property of their respective owners.
