# Arynox screenshots

This directory contains the original lossless PNG files used by the main
project README.

- `desktop/` contains nine native 1920 × 1080 desktop captures.
- `android/` contains five native 1080 × 2400 Android captures.
- `agentcall-showcase.png` is the README hero assembled from the Calls and
  Android Gateway source captures.

The Android and desktop files were moved here byte-for-byte. They were not
resized, recompressed, optimized, or otherwise re-encoded.
